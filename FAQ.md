# LIMS Console - FAQ

The product FAQ is available **in the app** under **FAQ** in the sidebar.

**Source of truth:** [`app/dashboard/faqContent.ts`](./app/dashboard/faqContent.ts)  
**UI:** [`app/dashboard/FaqPanel.tsx`](./app/dashboard/FaqPanel.tsx)

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) → **FAQ**.

Covers enterprise (demo vs production, walkthroughs, GxP/security caveats) and developer topics (stack, run/deploy, architecture, extension path).
